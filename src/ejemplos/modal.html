Modal nativo

Demostración local de contenido, formularios y tamaños. No guarda datos ni realiza solicitudes al backend.

Información dinámica

Formulario existente

El mismo formulario se traslada al modal y conserva su estado. Al cerrarlo permanece en el diálogo; al destruirlo vuelve aquí.

import { Modal } from '../js/boundary/componentes/overlays/index.js';
const modal = new Modal({ title: 'Información', size: 'medium' });
modal.setContent('Contenido seguro, sin interpretar HTML.');
modal.open();
