TarjetaConsulta

Consultas ficticias con distintas fechas. Una fecha de fin pasada no basta para mostrar «Finalizada»: se necesitan pasos completados del REST. Este ejemplo local no carga pasos.

import TarjetaConsulta from '../js/boundary/componentes/tarjeta_consulta.js';
const tarjeta = new TarjetaConsulta();
tarjeta.consulta = consulta; // Asignar antes de insertarla.
tarjeta.pasos = pasosDeEstaConsulta; // Pasos reales cargados por la página.
document.querySelector('#consultas-demo').append(tarjeta);

El componente presenta fecha, paciente, observaciones, clínica y estado. La navegación hacia Atención pertenece al controller de Consultas, no a la tarjeta.
